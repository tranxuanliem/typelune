# Typelune brand

**Name.** Typelune (say "TYPE-loon"). Write it as one word with a capital T. Never
"TypeLune" or "Type Lune". The graphic wordmark uses original lowercase letterforms; text references use **Typelune**. It joins *type* and *lune* (French for moon): a calm tool that
turns a short typed mark into a full line of text.

**Tone.** Calm, exact, modest. Say what it does and where its limits are. No superlatives,
and no claims of App Store or notarized status until they are true.

## Mark

A crescent moon (the *lune*: the short abbreviation you type) leads into a long line (the
expanded text), ending in a caret.

| File | Use |
|---|---|
| `assets/brand/icon-layer.svg` | **Layer source.** A full-bleed, unmasked 1024×1024 square with no rounded corners and no shadow, following Apple's guidance for modern icon layers. Its named groups `background`, `lune`, `line` and `caret` are the separable layers. |
| `assets/brand/icon-macos.svg` | Classic macOS icon for 128–1024 px. The same art on an 824×824 body, corner radius 185, centred in 1024. Transparent outside the body. |
| `assets/brand/icon-macos-small.svg` | Hand-tuned for 16, 32 and 64 px. The crescent is larger, the line thicker, and there is no caret or gradient, so both shapes still read at 16 px. |
| `assets/brand/Typelune.icns` | Generated by `scripts/make-icon.sh`, which renders every slot at its own pixel size with AppKit and checks transparency. Committed to the repo. |
| `assets/brand/wordmark.svg`, `wordmark-on-ink.svg` | Wordmark. Original monoline letterforms drawn as stroked paths: no font files and no font outlines. |

All artwork is original and released under the project's MIT licence. The crescent is
drawn as one exact two-arc path (circle (352,452) r196 minus circle (420,388) r168), not
as a mask, so every renderer anti-aliases it the same way.

## Type and UI

The app uses **system** fonts, colours, SF Symbols and the user's accent colour, so it
follows light and dark mode, increased contrast and the user's settings. Brand colours
appear only in the icon and in documentation art. The wordmark is never set in SF fonts.

## Clear space and minimum sizes

- Keep clear space of at least one third of the icon height around the icon.
- Minimum sizes: icon 16 px, wordmark 64 px wide.

## Design references

The icon source and system typography follow Apple’s [app icon guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons) and [typography guidance](https://developer.apple.com/design/human-interface-guidelines/typography). Classic ICNS is the current deliverable; modern Icon Composer layers are source artwork for a future signed release.

The name was selected with Claude Opus 5.5 after rejecting software name collisions. Limited web, GitHub and US Mac App Store searches on 2026-10-13 found no obvious exact software-name match for Typelune.
